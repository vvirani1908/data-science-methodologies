# Data Mining Process Assignment

This repository demonstrates three complete data-science projects using three different datasets and three different methodologies.

## Projects

| Methodology | Dataset | Analysis type |
|---|---|---|
| CRISP-DM | Telco Customer Churn | Churn classification |
| SEMMA | Titanic Passenger Survival | Classification |
| KDD | Mall Customer Segmentation | Clustering |

## Dataset sources

- Telco Customer Churn: [Kaggle dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
- Titanic: [Kaggle competition dataset](https://www.kaggle.com/competitions/titanic/data)
- Mall Customer Segmentation: [Kaggle dataset](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python)

The notebooks use reproducible public raw-data mirrors for Colab execution. The Kaggle links above identify the original dataset sources.

## Reproducibility

Open each notebook in Google Colab, run all cells from top to bottom, and save the notebook with outputs. The notebooks record the random seeds, preprocessing decisions, evaluation metrics, limitations, and deployment or operational recommendations.

## Responsible use

These are educational analyses. Predictive results are not causal evidence, clusters are not permanent identities, and any real deployment would require privacy review, monitoring, human oversight, and validation with current data.
